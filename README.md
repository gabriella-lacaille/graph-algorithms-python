# Graph Algorithms in Python

This repository contains Python implementations of graph algorithms and data structures developed as part of my Computer Science coursework at the State University of Rio de Janeiro (UERJ), Brazil.

## Overview

The project focuses on applying fundamental concepts of Graph Theory through practical programming exercises.

It explores graph representations and algorithmic approaches to solving computational problems.
